# 快速接入流程

## 接入步骤

### 1. 注册

访问 [CodeFlow](https://codeflow.asia/)，点击「免费注册」。核验时平台支持使用邮箱注册，无需海外手机号；实际可用的注册方式以页面显示为准。

### 2. 充值

::: info 充值数据来源与核验
- **来源**：[CodeFlow「充值优惠」](https://codeflow.asia/#packages)
- **核验范围**：基础换算、充值套餐优惠与余额有效期
- **最后核验日期**：2026 年 8 月 18 日

充值规则和套餐折扣可能调整，付款前请以控制台实时显示为准。
:::

进入 **账户充值**，选择预设档位或输入自定义金额，并按页面提示完成支付宝付款。付款成功后额度通常会自动到账；若长时间未到账，请保留订单号并提交工单。

![账户充值](../assets/images/quick-start/account-recharge.png)

> 上图为 2026 年 8 月 20 日的界面留档，未反映当前充值套餐折扣。实际付款金额与到账额度以充值页面实时显示为准。

换算比例、优惠、最低金额和余额有效期均可能调整，付款前请以充值页面为准。

### 3. 创建令牌

进入 **令牌管理 → 创建令牌**，填写名称、选择分组、按需设置费用限制，创建后复制密钥。

### 4. 配置工具

前往 [软件教程](../tools/index.md)，根据所使用的客户端填写 Base URL 和令牌。

如果使用 Claude Code 或 Codex，也可以通过 [CodeFlow 命令行工具](./codeflow-cli.md#一键配置-claude-code-与-codex) 自动写入配置。

### 5. 验证

启动客户端并发起一条测试消息。客户端能够收到正常响应，即表示基本连接已建立。

**数据看板** 显示账户余额、当日请求数、Token 用量与消耗：

![数据看板](../assets/images/quick-start/usage-dashboard.png)

**使用日志** 逐条显示每次调用的输入／输出 Token 与对应金额：

![使用日志](../assets/images/quick-start/usage-log.png)

## 遇到问题怎么办

|现象|大致处理方式|
|---|---|
|返回 401 或提示认证失败|重新复制令牌，确认没有多余空格；令牌若已丢失或疑似泄露，删除后重新创建。|
|返回 404 或提示模型不存在|确认模型 ID 拼写正确，并检查令牌分组是否匹配：`gpt-*` 模型使用 Codex 官方分组，`claude-*` 模型使用 Claude 分组。|
|提示余额不足|按照核验时的预扣规则，确认可用余额不低于 $1；使用订阅时，检查当前额度是否已用完，并以订阅页显示的恢复时间为准。|
|工具无法连接|按对应工具教程检查 Base URL，尤其确认该工具是否要求地址末尾带 `/v1`。|
|充值后未到账|先刷新账户充值页并核对充值记录；仍未到账时，保留支付订单号并联系 CodeFlow 客服。|
