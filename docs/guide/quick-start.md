# 快速接入流程

## 接入步骤

### 1. 注册

访问 https://codeflow.asia/ ，点击「免费注册」。邮箱注册即可，无需海外手机号。

### 2. 充值

::: info 充值数据来源与核验
- **来源**：[CodeFlow「充值优惠」](https://codeflow.asia/#packages)
- **核验范围**：基础换算、充值套餐优惠与余额有效期
- **最后核验日期**：2026 年 8 月 18 日

本节已与 CodeFlow 公开页面逐项核对。充值规则和套餐折扣可能调整，付款前请以控制台实时显示为准。
:::

进入 **账户充值**，选择档位或输入自定义金额，支付宝付款，即时到账。

![账户充值](../assets/images/image-16.png)

> 上图为 2026 年 7 月 31 日的界面留档，未反映当前充值套餐折扣。实际付款金额与到账额度以充值页面实时显示为准。

基础换算公开为 **¥1 = $5.00 额度**；预设充值套餐在此基础上提供 **9.8 折至 8.5 折**优惠，余额永不过期。最低 ¥1 起充，实际付款金额与到账额度以充值页面实时显示为准。

### 3. 创建令牌

进入 **令牌管理 → 创建令牌**，填写名称、选择分组、按需设置费用限制，创建后当场复制密钥。

### 4. 配置工具

参照下文对应章节，填入接口地址与令牌。

### 5. 验证

启动工具并发起一次对话。返回正常即接入成功。

## 遇到问题怎么办

|现象|大致处理方式|
|---|---|
|返回 401 或提示认证失败|重新复制令牌，确认没有多余空格；令牌若已丢失或疑似泄露，删除后重新创建。|
|返回 404 或提示模型不存在|确认模型 ID 拼写正确，并检查令牌分组是否匹配：GPT 模型使用 Codex 官方分组，Claude 模型使用 Claude 分组。|
|提示余额不足|确认可用余额不低于 $1；使用订阅时检查每日额度是否已经用完，并以订阅页显示的恢复时间为准。|
|工具无法连接|按对应工具教程检查 Base URL，尤其确认该工具是否要求地址末尾带 `/v1`。|
|充值后未到账|先刷新账户充值页并核对充值记录；仍未到账时，保留支付订单号并联系 CodeFlow 客服。|
